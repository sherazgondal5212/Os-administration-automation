# Operating System Administration & Automation

A hands-on portfolio project covering Linux administration,
Bash automation, Amazon Linux, Windows Batch and PowerShell.

## Project Modules

- Linux Administration: files, permissions, processes and services
- System Monitoring: CPU, memory, disk and uptime
- Bash Automation: health checks, backups and logging
- Amazon Linux: package and service management
- Windows: Batch scripting and PowerShell
- Documentation: testing procedures and sample outputs

## Environment

- AWS CloudShell
- Amazon Linux 2023
- AWS CLI
- Git

## Important

CloudShell is the development workspace. Scripts requiring
OS-level privileges or services must be tested on the appropriate
Linux or Windows server environment.
